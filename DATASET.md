# Dataset: CapMIT1003

## Project
Can Vision Transformers Predict Human Visual Attention?

## Dataset Source
CapMIT1003 GitHub repository:
https://github.com/mad-lab-fau/CapMIT1003

## Dataset Description
CapMIT1003 contains human-generated image captions and recorded click locations associated with images from the MIT1003 dataset. The data is provided in a SQLite database, with Python utilities for accessing it.

## Relevance to Our Project
We plan to investigate whether visual models, including Vision Transformers, can predict human visual attention. CapMIT1003 may help us explore click-based attention patterns. Click locations should not automatically be treated as equivalent to eye-tracking fixations.

## How to Access the Data
1. Visit the original CapMIT1003 repository linked above.
2. Follow its README to obtain the database and Python utilities.
3. Download the associated MIT1003 images as described by the original repository.
4. Inspect the data before selecting a prediction target or evaluation metric.

## Current Status
The dataset has been identified as a potential source. Data preprocessing, model training and evaluation have not yet been completed.
